핵심 기능 

1. 롤(LoL) 방식의 파티 자동 채움 매칭 시스템
- 원하는 인원 설정: 2:2, 3:3, 4:4 규모 중 원하는 매칭 타입을 선택하여 로비를 생성합니다.
- 초대 코드 시스템: 고유한 초대 코드를 공유하여 지인들과 안전하게 같은 파티를 구성할 수 있습니다.
- 자동 채움 (Auto-fill): 4:4를 고르고 친구 2명만 초대해 자리가 비어도(총 3명), '매칭 시작'을 누르면 시스템이 대기열의 솔로 유저를 탐색해 **동성 4인 팀을 자동으로 완성**한 뒤 이성 팀과 매칭합니다.

2. 동기 단절 모드 (학과 필터링 알고리즘)
- 과팅 자리에서 같은 과 동기를 만나 뻘쭘해지는 대참사를 방지합니다.
- 팀이 완성되면 팀원들의 학과를 수집하여 '기피 학과 배열'을 생성하며, 최종 이성 팀 매칭 시 **학과 교집합이 단 하나라도 존재하면 매칭을 스킵**하고 다음 대기열을 탐색합니다.

3. 위치 기반(Geofencing) 체크인 및 노쇼 방지
- QR 코드 폐지: 번거로운 QR 코드 스캔 대신, 약속 장소 반경 100m 이내 진입 시 앱에서 자동으로 도착 확인 알림을 보냅니다.
- 상호 근접 인증: 두 팀이 모두 체크인하고 GPS 상 거리가 10m 이내로 일정 시간 유지되면 최종 '만남 성공'으로 판정합니다.
- 노쇼 실시간 판별: 약속 시간이 지났을 때 현장 체크인 기록이 없는 팀을 데이터(GPS) 기반으로 정확히 판별하여 페널티를 부과합니다.

4. 대화형 UI 통합 예약 시스템
- 채팅창 내부에서 약속 장소 예약 및 시간 변경을 카드 형태로 주고받을 수 있습니다.
- 한 팀이 시간 변경을 요청하고 상대 팀이 승인하면, 백엔드상의 약속 시간과 지오펜싱(체크인 활성화 시간)이 실시간으로 동기화됩니다.
